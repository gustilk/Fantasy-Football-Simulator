---
name: Weekly simulation intent
description: Why whole-week Game Simulator batches must remain distinct from Sunday forecasts and salary-defined contests.
---

The user wants one-click simulation of every game in the selected NFL week rather than selecting and running each matchup individually.

**Why:** The user said, “all the games for week 4, doing one by one is inconvenient.”

**How to apply:** Do not replace the selected-week scope with the existing Sunday-only forecast group. A whole-week simulation group is also not automatically a DraftKings contest slate; contest membership still comes from the uploaded salary file.
